# Programación Orientada a Objetos

Repositorio con los códigos desarrollados en las clases de teoría y laboratorio de la materia de **Programación Orientada a Objetos**.

## 📂 Contenido del Repositorio

Este repositorio está organizado en diversas prácticas, ejercicios y proyectos que ilustran los conceptos fundamentales de Java y la POO:

### Ejercicios y Prácticas

- **Excepciones:** Códigos para comprender el manejo de errores en Java. Incluye ejemplos de división entre cero, uso de bloques `try-catch` anidados y captura de múltiples excepciones simultáneas (`Multicatch`, `TryAnidados`).
- **Práctica 3 (Manejo de Cadenas):** Uso intensivo de los métodos de la clase `String` y validaciones básicas de datos por consola (ej. validación en `ComprobarNIF` y `UsarMetodosString`).
- **Práctica 8 (Herencia e Interfaces):** Estructura orientada a objetos para videojuegos utilizando interfaces (`Jugable`) y herencia de clases (`Juego`), aplicado en la creación de un `JuegoAhorcado`.

### 🎮 Proyectos Destacados

#### 💣 Buscaminas (`Proyecto Buscaminas`)
Implementación en consola del clásico juego Buscaminas. Destaca por el uso de:
- Arreglos bidimensionales (`matrices`) para la gestión del tablero.
- Colecciones de datos (`ArrayList`, `Iterator`) para el seguimiento de minas y casillas destapadas.
- Creación de excepciones personalizadas (`ExceptionValidacionLetras`, `ExceptionValidacionNumeros`) para la lectura segura de las coordenadas ingresadas por el usuario.

#### 📒 Agenda de Contactos (`ABCD / fi.unam`)
Un sistema de gestión (CRUD) interactivo mediante consola para administrar contactos telefónicos.
- Implementación de menús interactivos.
- Arquitectura dividida en paquetes lógicos (`fi.unam.io`, `fi.unam.principal`).
- Persistencia de datos simulada y operaciones de entrada/salida (I/O) utilizando archivos de texto.
